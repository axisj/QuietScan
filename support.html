고객지원

사용 방법과 문제 해결 안내입니다. 문의는 GitHub Issues로 받습니다.

문장을 수집하는 방법

  1. 카메라 접근을 허용하고 책이나 문서를 비춰 주세요.
  2. 영역 선택에서 초록색 사각형을 드래그하거나 모서리를 조절하세요. 전체 화면을 선택하면 뷰파인더 전체를 인식합니다.
  3. 글자 위에 인식 표시가 생기고 복사 버튼이 활성화되면 복사를 누르세요. 클립보드에 복사하고 수집함에도 저장합니다.
  4. 복사 오른쪽의 일시정지·재생 버튼으로 라이브 스캔을 끄고 켤 수 있습니다.
  5. 상단 수집함에서 내용을 수정·삭제·정렬하거나 전체 복사·공유하세요.

지원 환경

iOS 17 이상과 Apple의 라이브 텍스트 스캐너를 지원하는 iPhone이 필요합니다. 모든 기기에서 사용할 수 있는 기능은 아닙니다. 앱에서 지원 여부와 카메라 권한을 확인하고 안내합니다. 한국어·영어 인식을 지원하며 앱 표시는 기기 또는 앱 언어 설정을 따릅니다.

인식이 안 되거나 복사가 비활성화돼요

라이브 스캔과 카메라 권한을 확인하세요. 문서를 밝고 평평하게 놓고 글자가 선택 영역 안에 들어오게 맞춘 뒤 잠시 기다려 주세요. 작은 글자는 기기를 가까이 대고, 반사광이나 흔들림을 줄여 보세요. 영역을 옮기거나 스캔을 재개하면 새 결과가 준비될 때까지 복사를 기다립니다.

저장한 텍스트를 지우고 싶어요

수집함의 휴지통 버튼이나 스와이프로 개별 삭제할 수 있습니다. 하단 휴지통은 확인 후 전체 삭제합니다. 앱 자체에는 삭제 취소 기능이 없습니다.

사진이나 인터넷 연결이 필요한가요?

사진을 촬영하거나 이미지 파일을 저장하지 않습니다. OCR과 수집함의 기본 기능은 인터넷 연결 없이 사용할 수 있습니다. 이 웹사이트, GitHub 문의 및 사용자가 선택한 온라인 공유 서비스에는 인터넷 연결이 필요합니다.

저장 내용이 사라졌어요

같은 기기의 같은 앱인지, 앱을 삭제했거나 기기를 변경했는지 확인해 주세요. 개발자 서버에 텍스트를 보관하지 않아 개발자가 원격으로 복구할 수 없습니다. 앱 자체 동기화는 제공하지 않으며, 기기 백업 복원 여부는 Apple의 백업 기능에서 확인해 주세요.

문제 신고와 제안

앱 버전, iPhone 모델, iOS 버전, 재현 순서를 적어 주세요. GitHub 계정으로 로그인하면 이슈를 작성할 수 있습니다. 모든 이슈는 공개됩니다. 개인정보나 민감한 문서 내용은 올리지 마세요. 화면을 첨부할 때는 내용을 가려 주세요.
