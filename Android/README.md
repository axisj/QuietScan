# ScanClip Android 테스트판

[**APK 다운로드 — 1.0.0 (1)**](https://github.com/axisj/ScanClip/releases/download/android-v1.0.0-test.1/ScanClip-Android-1.0.0-test.apk) · [릴리스 안내](https://github.com/axisj/ScanClip/releases/tag/android-v1.0.0-test.1) · [English](README.en.md)

사진을 찍지 않고 책·문서의 한국어와 영어 텍스트를 실시간으로 인식하고, 필요한 문장을 복사해 기기에 모으는 앱입니다.

## 설치

1. **Android 8.0 이상** 휴대폰에서 위 APK 다운로드 링크를 엽니다. 파일 크기는 약 63MB입니다.
2. 다운로드한 `ScanClip-Android-1.0.0-test.apk` 파일을 엽니다.
3. 요청되면 파일을 연 브라우저나 파일 앱의 **출처를 알 수 없는 앱 설치**를 허용하고 설치합니다.
4. ScanClip을 실행한 뒤 카메라 권한을 허용합니다.

Google Play 등록 전 테스트판입니다. 실기기 카메라 품질은 아직 검증하지 않았습니다. 개발용 키로 서명되어 있으며, 향후 정식판에서 서명 키가 바뀌면 재설치가 필요할 수 있습니다. 전환 전 수집함의 전체 복사·공유로 필요한 내용을 보관하세요.

## 포함된 기능

- 한국어·영어 오프라인 OCR, 선택 영역 이동·크기 조절, 인식 하이라이트, 전체 화면 인식
- 스캔 시작·일시정지, 저장 성공 후 복사, 중복 저장 확인
- 수집함 추가·수정·삭제·순서 변경·전체 복사·공유, 재실행 후 복원
- 한국어·영어 화면 및 앱 내부 개인정보 안내

카메라 프레임과 사진 파일을 보관하거나 개발자 서버에 보내지 않습니다. OCR 모델이 앱에 포함되어 있으며 앱 자체에는 인터넷 권한이 없습니다. 수집함은 기기에만 보관하고 자동 백업·기기 전송을 끕니다. **앱을 삭제하면 수집함도 삭제됩니다.**

## 확인한 범위

Android 14 에뮬레이터에서 코어 11개와 기기 테스트 16개, 총 27개가 통과했습니다. OCR은 한글·영문 테스트 이미지로 확인했습니다. 실제 휴대폰에서의 초점·손떨림·연속 인식 속도·발열은 추가 확인이 필요합니다.
