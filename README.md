Hosted by GitHub Pages from `main` / root. Static HTML and CSS only; no additional analytics, advertising, external fonts, or JavaScript. The app's source code and credentials are not part of this repository.

To update the documentation, edit the relevant `.html` files and push to `main`. Keep Korean and English content consistent and update the privacy policy's date when its substance changes. GitHub Issues are public; do not include personal information or sensitive documents.
