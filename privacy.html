개인정보처리방침

이 방침은 AXISJ Co., Ltd.가 제공하는 QuietScan iOS 앱에 적용됩니다. 아래에는 앱에서 처리하는 정보와 사용자가 직접 선택하는 외부 서비스 이용을 구분해 설명합니다.

카메라 영상과 인식한 텍스트를 개발자 서버로 보내지 않습니다.

카메라와 텍스트 인식

카메라는 라이브 텍스트 인식을 위해 사용합니다. 영상은 인식 중 메모리에서 처리하며, 앱은 사진 촬영 기능을 호출하거나 원본 사진·카메라 프레임을 파일로 저장하지 않습니다. OCR은 Apple의 기기 내 인식 기능을 사용하며, 앱은 영상이나 인식 텍스트를 개발자 서버에 업로드하지 않습니다. 카메라 접근은 iOS 권한으로 제어됩니다.

수집함에 저장되는 정보

복사·수집하거나 직접 입력한 텍스트, 생성 시각, 항목 식별자와 정렬 순서를 앱의 로컬 저장소에 보관합니다. QuietScan은 자체 클라우드 동기화나 계정 기능을 제공하지 않으며 CloudKit 동기화를 사용하지 않습니다. 저장한 내용은 사용자가 삭제할 때까지 기기에 남습니다.

복사와 공유

복사를 누르면 선택한 텍스트를 iOS 클립보드에 기록합니다. 기기 설정에 따라 Apple의 공통 클립보드 기능이 적용될 수 있습니다. 공유를 선택하면 사용자가 고른 다른 앱이나 서비스에 텍스트가 전달됩니다. 전달된 사본은 해당 서비스의 정책과 사용자가 정한 설정에 따라 처리되며 QuietScan에서 삭제해도 자동 삭제되지 않습니다.

광고·분석·추적

현재 앱에는 광고 SDK, 개발자용 이용 분석 SDK 또는 제3자 추적 SDK가 없습니다. 개발자는 앱을 통해 카메라 영상, 수집 텍스트 또는 이용 기록을 수집하지 않습니다. Apple의 App Store·TestFlight 및 사용자가 허용한 시스템 진단은 Apple의 정책과 기기 설정에 따라 별도로 처리될 수 있습니다.

삭제, 권한과 기기 백업

수집함의 개별 삭제 또는 전체 삭제로 앱에 저장된 텍스트를 삭제할 수 있습니다. 앱을 삭제하면 기기에 있는 앱 데이터도 제거됩니다. 앱 정리하기(오프로드)는 데이터를 유지할 수 있습니다. iOS 설정에서 카메라 권한을 변경할 수 있습니다. 로컬 앱 데이터는 사용자 설정에 따라 iCloud 또는 컴퓨터의 기기 백업에 포함될 수 있으며, 백업 사본과 복원은 Apple의 백업 기능에서 관리합니다. 클립보드·공유 대상·백업에 남은 사본은 별도로 관리해야 합니다.

안내 웹사이트와 문의

이 안내 사이트는 GitHub Pages에서 제공하며, 사이트에 별도의 광고·분석 스크립트를 넣지 않았습니다. 페이지 접속과 GitHub Issues 이용 시 GitHub가 접속 정보 및 사용자가 제출한 내용을 자체 정책에 따라 처리할 수 있습니다. GitHub Issues는 공개되므로 개인정보, 원문 문서, 카메라 이미지 등 민감한 내용을 게시하지 마세요. 개인정보 관련 질문과 삭제 방법에 대한 문의도 아래 문의처를 이용해 주세요.
